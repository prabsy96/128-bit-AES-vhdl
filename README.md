# 128-bit-AES-vhdl
This is my implementation of the 128 bit Advanced Encryption Standard in vhdl

What is AES?
The RIJNDAEL Advanced Encryption Standard(AES) is a specification for the encryption of electronic data chosen by the National Institute of standard and Technology(NIST), USA. It was proposed by two Belgian cryptographers Joan Daemen and Vincent Rijmen, and has become the most popular symmetric encryption 	algorithm today.
AES was developed as a replacement for Data Encrption Standard(DES), which had become vulnerable to exhaustive search. NIST adopted three members of the RIJNDAEL family, each with block size of 128 bits, but with three different key lengths of 128, 192 and 256 bits.
For this project, I am implementing a 128 bit version of AES.
